Modular LCEL Architecture

Engineered for High Reliability & Speed

Every stage in the pipeline is engineered with deterministic validation, strict type hints, and automated Pytest harnesses:

STAGE 01 src/ingest.py
Ingestion & Normalization
• 1-Indexed Offset: PyPDF 0-indexed pages mapped to physical page + 1.
• SHA-256 Digest: Byte hashing skips duplicate indexing.
• Scanned PDF Guard: Text-density check raises ScannedPDFError.
STAGE 02 FastEmbed ONNX
Quantized ONNX Embeddings
• Model: BAAI/bge-small-en-v1.5 (384-dimensional).
• Runtime: Stripped 800MB PyTorch dependency completely.
• Efficiency: 2.22s cold start, only +136MB memory footprint.
STAGE 03 src/retriever.py
Ephemeral Vector Store
• Zero Disk Retention: Collections live in RAM via EphemeralClient.
• Session Isolation: Keyed to unique session UUIDs.
• LRU Eviction Cap: Active collections capped at 10 to avoid leaks.
STAGE 04 src/chain.py
Two-Layer Guardrails
• Layer 1 Gate: Vector cosine similarity threshold (s >= 0.48).
• Layer 2 Grounding: XML <document_context> prompt isolation.
• Conditional Rewriter: History contextualizer only runs on Turn 2+.
