Why Toy Tutorial RAG Fails in Production & How We Engineered a Solution

Most generative AI tutorials connect a toy vector store to an LLM in a Jupyter notebook. When deployed to real cloud infrastructure with real medical policies, three fatal bottlenecks emerge:

✕ The Production Bottlenecks
  • • OOM Crashes: 800MB PyTorch wheels exceed 1GB serverless caps, crashing container runtimes.
  • • Data Leaks: Shared persistent disk stores expose documents across concurrent sessions.
  • • Hallucinations: Irrelevant queries trigger expensive LLM calls that fabricate false policy answers.
✓ The ClinicDocs AI Architecture
  • • FastEmbed ONNX: Pure quantized ONNX runtime slashes RAM by 70% (423MB peak process).
  • • In-Memory Isolation: Ephemeral session UUID collections in RAM with LRU eviction cap (max 10).
  • • Two-Layer Refusal: Cosine similarity gate intercepts off-topic queries in <25ms with 0 tokens billed.
