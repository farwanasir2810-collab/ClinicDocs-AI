Toy Tutorials vs Real Production Systems

Standard Jupyter notebook RAG breaks under strict container resource limits, multi-tenant isolation requirements, and out-of-domain hallucinations:

❌ Heavy PyTorch OOM Crashes
Standard sentence-transformers imports heavy PyTorch wheels (~800MB), exceeding 1GB serverless caps and crashing containers.
✓ FastEmbed ONNX (70% Less RAM)
Quantized ONNX runtime (bge-small-en-v1.5) cold-starts in 2.22s and peaks at only 423.2MB RAM under full load.
❌ Multi-Tenant Data Leaks
Storing vector collections on shared persistent disk leaks previous users' confidential documents across sessions.
✓ Ephemeral RAM Isolation
Collections live strictly in memory (chromadb.EphemeralClient) tied to session UUIDs with an LRU cap (max 10). Zero disk footprint.
❌ Hallucinations & Wasted API Bills
Irrelevant queries invoke full LLM completions, burning expensive API tokens while fabricating unstated medical claims.
✓ Two-Layer Refusal Gate (<25ms)
Cosine similarity gate (s >= 0.48) halts unrelated queries at the vector stage in 18ms with 0 tokens billed ($0.00 spent).
