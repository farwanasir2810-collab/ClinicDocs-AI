Why Tutorials Lie To You

Tutorial Demos vs Production Systems

Standard tutorial RAG breaks under strict container resource limits, multi-tenant isolation requirements, and off-topic questions. Here is how I solved each:

01 • The PyTorch Memory Bloat Trap SOLUTION: FastEmbed ONNX

The Trap: Default sentence-transformers loads ~800MB PyTorch wheels. In 1GB serverless containers, cold starts crash instantly from Out-Of-Memory (OOM).

✓ My Production Fix: Quantized ONNX runtime (bge-small-en-v1.5). PyTorch stripped completely — cold starts in 2.22s and peaks at only 423MB RAM (70% savings).
02 • Multi-Tenant Data Leaks SOLUTION: Ephemeral RAM

The Trap: Saving vector collections to local disk files risks leaking confidential clinic documents across sessions and fills container disk space over time.

✓ My Production Fix: Pure in-memory vector store (chromadb.EphemeralClient) isolated by session UUIDs with automated LRU memory eviction. Zero disk traces left behind.
03 • Hallucinations & Wasted API Spend SOLUTION: Vector Math Gate

The Trap: Passing off-topic questions directly to LLMs burns costly API tokens and risks generating dangerous medical hallucinations.

✓ My Production Fix: Cosine similarity threshold (s >= 0.48). Unrelated queries are rejected in 18ms before invoking the LLM — $0.00 billed.
