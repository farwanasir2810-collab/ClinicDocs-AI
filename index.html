Production Architecture Deep-Dive

ClinicDocs AI: Production-Grade RAG

Open Streamlit App
✕ Why "Toy Tutorial RAG" Fails in Production
  • • OOM Crashes: Heavy PyTorch wheels (~800MB) exceed 1GB serverless caps, crashing container runtimes immediately.
  • • Data Contamination: Storing vector collections on shared persistent disk leaks private documents between concurrent sessions.
  • • Hallucinations & Token Waste: Irrelevant queries invoke full LLM completion, racking up API cost while producing fabricated answers.
✓ Farwa's Production-Hardened Architecture
  • • FastEmbed ONNX Runtime: Strips PyTorch completely, cutting memory footprint by 70% (peaks at only 423MB under full load).
  • • In-Memory Ephemeral Isolation: Session-keyed collections via chromadb.EphemeralClient() with LRU eviction cap guarantees zero cross-leakage.
  • • Two-Layer Refusal Gate: Intercepts OOD questions in <25ms with 0 LLM tokens, backed by strict prompt grounding for near-topic guardrails.
01

Two-Layer Refusal Gate

Layer 1 compares max cosine similarity ($s < 0.48$) and halts in 18ms. Layer 2 applies XML grounding prompts to catch deceptive near-topic queries without hallucinations.

02

Ephemeral Multi-Tenancy

Zero disk persistence. Vector stores live in ephemeral RAM tied to session UUIDs with an LRU cache capping active collections to 10 to prevent container memory leaks.

03

FastEmbed ONNX Vectorizer

Employs quantized ONNX runtime for BAAI/bge-small-en-v1.5. Cold start drops from 12.4s to 2.22s with a model memory delta of only +136MB.

04

1-Indexed Page Citations

Normalizes 0-indexed PyPDF page numbers to human-readable physical pages (page + 1). Every answer links directly to verified source document chunks.
